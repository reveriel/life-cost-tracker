プライバシーポリシー

制定日：2026年10月12日

生活費トラッカー（以下「本サービス」といいます）は、利用者の個人情報および入力データを適切に取り扱うことを重要な責務と考えています。 本プライバシーポリシー（以下「本ポリシー」といいます）は、本サービスにおける情報の取扱い方針を定めるものです。

1. 基本方針 — 入力内容はサーバーへ送信されません

本サービスは、支払い情報の登録・集計・グラフ描画・書き出しといったすべての処理を 利用者のブラウザ内（クライアントサイド）で行います。 電気代・家賃・国民年金・サブスクリプションなどの名称、金額、支払日、メモといった入力内容が、 当方のサーバーへ送信されることはありません。会員登録も不要です。

2. 保存されるデータ（localStorage）

本サービスは、入力された支払い情報をお使いのブラウザの localStorage（ブラウザ内ストレージ）にのみ保存します。 localStorage は利用者の端末の中に置かれる領域であり、当方がその内容を閲覧・取得・収集することはできません。 保存されるのは、次のようなデータです。

  • 登録した支払い項目（名称、カテゴリ、金額、支払い周期、次回支払日、メモ）
  • 画面表示言語の設定（日本語／中文）

これらのデータは当方の管理下にあるサーバーには保存されません。 そのため、ブラウザの閲覧データ（サイトデータ）を削除したり、別の端末・別のブラウザで開いたりすると、記録は表示されません。 大切な記録は、後述の「JSON の書き出し」機能を使って定期的にバックアップしてください。

3. .ics（カレンダー）書き出しについて

本サービスの「.ics を書き出す」機能は、登録された支払い予定からカレンダーファイルをブラウザ内で生成し、 利用者の端末にダウンロードするものです。生成したデータが当方のサーバーへ送信されることはありません。 書き出した .ics ファイルを Google カレンダーや Apple カレンダー等の外部サービスに読み込む場合、 その後のデータの取扱いは各外部サービスのプライバシーポリシーに従います。 同様に、JSON の書き出し・読み込みもすべて端末内で完結し、当方には送信されません。

4. 取得する情報

本サービスが取り扱う情報は、次のとおりです。

  • 入力フォームの内容 — ブラウザ内の localStorage にのみ保存され、当方のサーバーには送信・保存されません。
  • アクセスに関する技術情報 — 後述のアクセス解析により、IP アドレス・閲覧ページ・参照元・ブラウザの種類等が取得される場合があります。
  • お問い合わせ・フィードバックの内容 — 後述のフィードバックフォームから任意でお送りいただいた内容。

本サービスは、氏名・住所・電話番号・メールアドレス・口座情報・クレジットカード番号といった 個人を特定する情報の入力を求めません。また、それらを収集・保存することもありません。

5. アクセス解析（Cloudflare Web Analytics）

本サービスは、利用状況の把握とサービス改善のために Cloudflare Web Analytics を利用しています。 同サービスは Cookie を使用せず、個人を特定しない統計情報（ページビュー、参照元、国・地域、端末の種類など）を収集します。 取得される情報は Cloudflare, Inc. のプライバシーポリシーに従って取り扱われます。

6. フィードバックフォーム（Google フォーム）

本サービスの「ご意見・フィードバック」ボタンは Google フォーム を利用しています。 フォームへ任意でご記入いただいた内容（ご意見、任意でご入力いただいた連絡先等）は、Google LLC のサービスを通じて当方に送信され、 サービス改善およびお問い合わせ対応のためにのみ利用します。フォームへの入力は任意であり、入力しなくても本サービスのすべての機能をご利用いただけます。

また、本サイトの表示にはフォント配信サービス「Google Fonts」を利用しており、同サービスの利用に伴い、利用者の IP アドレス等の技術情報が同サービスの提供者に送信される場合があります。

7. Cookie 等の利用

本サービスは、ツールの動作のために Cookie を必要としません。 入力データはブラウザ内の localStorage に保存され、当方のサーバーには送信されません。 前記のアクセス解析（Cloudflare Web Analytics）は Cookie を使用しない方式で提供されています。

8. 利用目的

取得した情報は、次の目的で利用します。

  1. 本サービスの提供、維持、改善および新機能の開発のため
  2. お問い合わせ・フィードバックへの対応のため
  3. 利用状況の統計的な分析のため
  4. 法令に基づく対応のため

9. 第三者提供

当方は、次の場合を除き、取得した個人情報を第三者に提供しません。

  1. 利用者の同意がある場合
  2. 法令に基づく場合
  3. 人の生命、身体または財産の保護のために必要があり、本人の同意を得ることが困難な場合
  4. 本サービスの運営に必要な範囲で、業務委託先に取り扱いを委託する場合（この場合、当方は委託先を適切に監督します）

10. 安全管理措置

当方は、取り扱う情報の漏えい、滅失または毀損の防止その他の安全管理のために、必要かつ適切な措置を講じるよう努めます。 本サイトは通信の暗号化（HTTPS）に対応しています。

11. 開示・訂正・削除等の請求

利用者は、当方が保有するご自身の個人情報について、開示、訂正、追加または削除を求めることができます。 ご希望の場合は、下記のお問い合わせ窓口までご連絡ください。ご本人であることを確認のうえ、法令に従い、合理的な期間内に対応します。 なお、ブラウザ内（localStorage）に保存された支払いデータは当方の管理下にないため、当方による削除はできません。 ツール画面の「データ管理」または各操作により、利用者ご自身で削除してください。

12. 本ポリシーの変更

当方は、法令の変更やサービス内容の変更等に応じて、本ポリシーを変更することがあります。 変更後の本ポリシーは、本サイト上に掲示した時点から効力を生じるものとします。
